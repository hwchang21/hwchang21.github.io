# Huaiwen Chang academic website

This is the static GitHub Pages edition of the academic profile.

## Publishing

1. Create the public repository **hwchang21.github.io** under the GitHub account **hwchang21**.
2. Upload the contents of this folder to the repository root, preserving the filenames.
3. In the repository settings, enable GitHub Pages from the root of the publishing branch.
4. Confirm that **https://hwchang21.github.io/** loads without a sign-in requirement.
5. Recheck the current title, affiliation, degree status, and institutional email after any future career change.

## Search setup

After the public URL works:

1. Add it as the homepage in Google Scholar, ORCID, LinkedIn, and CNKI.
2. Verify it in Google Search Console.
3. Submit **sitemap.xml** and use URL Inspection to request indexing.
4. Keep the same primary name, **Huaiwen Chang**, across profiles. Retain **Huai-Wen Chang** and **常怀文** as alternate-name variants.

The final canonical URL is **https://hwchang21.github.io/**. The page is a plain static site and requires no build process.
